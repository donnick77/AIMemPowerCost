# AIMemPowerCost

Монитор энергопотребления **видеокарты NVIDIA и CPU** в реальном времени
для Windows 11.

Программа показывает:

- **нагрузку GPU** (%),
- **занятую видеопамять** (ГБ),
- **мощность GPU** (Ватт) + график за последние 5 минут,
- **температуру GPU**,
- **виджет CPU** в том же стиле:
  - **НАГРУЗКА CPU** (%) — реально, через `psutil`;
  - **ТЕМПЕРАТУРА CPU** — best-effort через ACPI (`root/wmi`),
    обычно требует запуск от имени администратора; без доступа честно
    показывает «н/д · нужен админ» (не выдумывает число);
  - **Мощность CPU** — калибруемая **оценка** (idle → макс по нагрузке),
    включается в итог в рублях; диапазон задаётся прямо в окне;
  - модель процессора (например `i9-13900K`) + свой график за 5 минут.
- **стоимость электроэнергии** в рублях — **за час, за день, за месяц**
  (с учётом мощности **и GPU, и CPU**).

Энергия (Вт·ч) интегрируется из реальных показаний мощности каждые 2 секунды
и сохраняется на диск, поэтому счётчики не сбрасываются при перезапуске.

## Запуск

Просто запустите `AIMemPowerCost.exe` (двойной клик).
Нужен установленный драйвер NVIDIA.

Тариф по умолчанию — **7.90 ₽/кВт·ч** (Москва, коммерческий/нежилое, 2026).
Его можно поменять прямо в окне программы — значение сохранится.

Оценка мощности CPU по умолчанию: **45–280 Вт** (idle → макс, под i9-13900K).
Диапазон задаётся в окне «Оценка мощности CPU» и сохраняется; итог в рублях
считывается с учётом и GPU, и CPU.

Температура CPU читается через ACPI-термозону (`root/wmi`). На большинстве
систем это требует **запуск от имени администратора**; без доступа в окне
будет «н/д · нужен админ» (число не выдумывается). Нагрузка и оценка
мощности CPU работают и без прав администратора.

> Источник тарифа: распоряжение Департамента экономической политики и
> развития города Москвы — единый котловой тариф за передачу электроэнергии
> (низкое напряжение, 1-е полугодие 2026) 1 283.66 ₽/МВт·ч; итоговая цена
> для юрлиц = генерация (биржа) + передача + наценка поставщика + НДС.

## Сборка exe из исходников

Нужен Python 3.10–3.12 (с tkinter):

```
pip install nvidia-ml-py psutil pywin32 pyinstaller
pyinstaller --onefile --windowed --name AIMemPowerCost \
    --icon icon.ico aimempowercost.py
```

Готовый файл появится в `dist/AIMemPowerCost.exe`.

Иконка:
- `icon.ico` — используется PyInstaller для иконки `.exe` (файл в корне);
- `icon.png` — 512×512, из неё при сборке встраивается 48×48 PNG (base64)
  в заголовок окна, поэтому картинка в GUI не зависит от внешних файлов.

## Самопроверка

```
python aimempowercost.py --selftest
```

Считывает реальные показания GPU и CPU ~6 секунд и проверяет, что энергия
накопилась (выходной код 0 = ок).

## Файлы

| Файл | Назначение |
|---|---|
| `aimempowercost.py` | вся программа (один файл) |
| `icon.ico` | иконка `.exe` (16–512 px) |
| `icon.png` | исходник иконки 512×512 |
| `%APPDATA%\AIMemPowerCost\state.json` | накопленные Вт·ч, тариф, оценка мощности CPU |

Кнопка «Сбросить счётчики» обнуляет накопленную энергию.
