# AIMemPowerCost

Монитор энергопотребления видеокарты NVIDIA в реальном времени для Windows 11.

Программа показывает:

- **нагрузку GPU** (%),
- **занятую видеопамять** (ГБ),
- **мощность** (Ватт) + график за последние 5 минут,
- **температуру**,
- **стоимость электроэнергии** в рублях — **за час, за день, за месяц**.

Энергия (Вт·ч) интегрируется из реальных показаний мощности каждые 2 секунды
и сохраняется на диск, поэтому счётчики не сбрасываются при перезапуске.

## Запуск

Просто запустите `AIMemPowerCost.exe` (двойной клик).
Нужен установленный драйвер NVIDIA.

Тариф по умолчанию — **7.90 ₽/кВт·ч** (Москва, коммерческий/нежилое, 2026).
Его можно поменять прямо в окне программы — значение сохранится.

> Источник тарифа: распоряжение Департамента экономической политики и
> развития города Москвы — единый котловой тариф за передачу электроэнергии
> (низкое напряжение, 1-е полугодие 2026) 1 283.66 ₽/МВт·ч; итоговая цена
> для юрлиц = генерация (биржа) + передача + наценка поставщика + НДС.

## Сборка exe из исходников

Нужен Python 3.10–3.12 (с tkinter):

```
pip install nvidia-ml-py pyinstaller
pyinstaller --onefile --windowed --name AIMemPowerCost aimempowercost.py
```

Готовый файл появится в `dist/AIMemPowerCost.exe`.

## Самопроверка

```
python aimempowercost.py --selftest
```

Считывает реальные показания GPU ~6 секунд и проверяет, что энергия
накопилась (выходной код 0 = ок).

## Файлы

| Файл | Назначение |
|---|---|
| `aimempowercost.py` | вся программа (один файл) |
| `%APPDATA%\AIMemPowerCost\state.json` | накопленные Вт·ч, тариф |

Кнопка «Сбросить счётчики» обнуляет накопленную энергию.
